# Caio Sabino — Portfolio

Personal portfolio for Caio Sabino, a Software Engineering student at the
University of Brasília looking for a development internship. A static,
single-page, bilingual (Portuguese/English) site presenting his experience,
projects and skills.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS v4
- [shadcn/ui](https://ui.shadcn.com)
- Deployed on [Vercel](https://vercel.com)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the site.

## Content

All page copy lives in `content/pt.ts` and `content/en.ts`, both typed
against the shared `SiteContent` interface in `content/types.ts`.
